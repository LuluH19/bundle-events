---
name: bundle-walkthrough
description: Explain how a Bundle Events feature works or identify the right place for a small edit.
---

Start from the screen, URL, or interaction the teammate names. Find the handler that actually runs. Trace one concrete value through the relevant component or hook into the route, service, adapter, or persisted state. Stop once the question is answered. For a placement question, compare an existing sibling feature and identify which layer owns the decision.

Give the shortest useful call path with file and symbol references. For example, when asked where a hotel label comes from, distinguish the component rendering the text from the adapter normalizing the hotel's name. End with the first file to edit or inspect and one way to observe the result. Keep a walkthrough read-only unless implementation was requested.
